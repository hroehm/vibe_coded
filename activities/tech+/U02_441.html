Programming Organization

Mastering the planning process for software development. Learn how to think like a computer and communicate effectively with your programming team.

The Planning Process

  • 1. Problem Identification: Identify the Inputs, Processes, Storage needs, and Outputs.
  • 2. Visualize Solution: Draw out how the problem will be solved using a Flowchart.
  • 3. Turn Visuals to Words: Write out the logic using Pseudocode.
  • 4. Document Work: Add comments to explain sections to other developers.

Logic Concepts

Controls how a program behaves.

  • Branching (If-Then-Else): Changes in program sequence based on a logical test. Example: If age < 13, show G rating.
  • Looping: Repeats a block of code until a condition is met.
    • For Loop: Runs a specific number of times (uses a counter).
    • While Loop: Runs as long as a condition remains true (e.g., waiting for valid input).

Flowcharts & Pseudocode

Flowchart Symbols:

  • Oval Start/End: Begins or terminates the flow.
  • Para Input/Output: Receiving data or displaying results.
  • Rect Process: Calculations or variable assignments.
  • Decision (Diamond): Logical test resulting in branching paths (Yes/No).

Pseudocode:

"Almost code" - human-readable algorithm description.

// Example: Movie Rating
ASK user to input age
IF age < 13 THEN
  DISPLAY "G"
ELSE IF age < 17 THEN
  DISPLAY "PG or PG-13"
ELSE
  DISPLAY "R"
END IF

Object-Oriented Methods (OOP)

Structures code by abstracting everyday concepts into common object templates.

  • Class: The template for similar objects (e.g., Human).
  • Properties: Attributes of the object (e.g., Height, Age, Hair Color).
  • Methods: Actions the object can perform (e.g., Walk, Work, Play).

Documentation & Comments

Crucial for explaining the program to other developers and yourself in the future. The computer ignores comments.

  • # - Used in Python, Ruby, Shell.
  • // - Used in Java, C++, JavaScript.
  • /* */ - Block comments for multiple lines.
