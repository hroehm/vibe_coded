GitHub Pages Workflow

By using GitHub Pages, you can host this activity online so students don't have to juggle files. The app will automatically read your questions from GitHub!

Step 1: Download Required Files

You need this web app and the question template. Save them to your computer.

Step 2: Edit & Upload to GitHub

Open questions.csv in Excel, adjust the Start/End years and Period Title in the first row, add your questions, and save it. (Ensure the name remains exactly questions.csv).

  • Create a new public repository on GitHub.
  • Upload both index.html (this file) and questions.csv to the root of the repository.
  • Go to repository Settings > Pages, set the source to the "main" branch, and save.

Step 3: Share Link & Collect Results

GitHub will provide a live link (e.g., yourname.github.io/apush-review/). Share this link with your students. When they finish, they will generate a certificate image to upload directly to Schoology!
