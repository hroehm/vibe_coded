OBJECTS & CLASSES

Modeling Real-World Objects

Class

A blueprint or template used to create objects. It defines the default properties and methods for a base version of an object.

public class Car { ... }

Classes are the primary tool used for encapsulation in OOP. By creating a Class, you establish a framework for common objects that you plan to reuse throughout your code. It serves as a master template ensuring every object built from it starts with the same base structure and capabilities.

Object / Instance

An instance of a class. The most basic building block of OOP, made up of properties and methods. Requires an identity (name).

Car myCar = new Car();

Instantiation is the process of creating a new instance, a concrete version, of a class. When you instantiate an object, you assign it an identity (a named variable) and it initializes the default properties defined in the class. Once created, you can interact with its unique state and call its methods.

Properties (State)

A description of characteristics of an object. These are the "nouns" or "adjectives". What makes the object unique?

  • color = "blue"
  • fuelLevel = 100
  • type = "sedan"

Properties define the State of an object. While the terms "property" and "attribute" are often used interchangeably, a property is the characteristic itself (e.g., eye color), whereas the attribute is the specific value assigned to it (e.g., 'blue').

Methods (Behaviors)

Actions, or functions, that an object can do. These are the "verbs". Often referred to as "getters" and "setters".

  • accelerate()
  • addFuel(5)
  • turnOn()

Methods dictate the Behaviors of an object. Two common types are getters and setters. A "getter" method retrieves data or a property from the object. A "setter" method updates or modifies a property. Methods allow objects to interact with each other and process logic.

Encapsulation

Bundling data (properties) and methods together to promote modularity and organization. This is the primary reason we use Classes in programming!

Encapsulation is one of the fundamental principles of Object-Oriented Programming. By bundling properties and methods into a single unit (the class), you hide the internal state of the object from outside interference and misuse. Code outside the object must use the designated methods (like getters/setters) to interact with the object's data.
