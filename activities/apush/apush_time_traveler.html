GitHub Pages + Outlook Workflow

By using GitHub Pages, you can host this activity online so students don't have to juggle files. The app will automatically read your questions from GitHub!

Step 1: Download Required Files

You need this web app and the question template. Save them to your computer.

Step 2: Edit & Upload to GitHub

Open questions.csv in Excel, add your questions, and save it. (Ensure the name remains exactly questions.csv).

  • Create a new public repository on GitHub.
  • Upload both index.html and questions.csv to the root of the repository.
  • Go to repository Settings > Pages, set the source to the "main" branch, and save.

Step 3: Share Link & Collect Results

GitHub will provide a live link (e.g., yourname.github.io/apush-review/). Email this link to your students via Outlook. When they finish, they will click a button that automatically drafts an Outlook email to you with their score and an Excel-ready data row. No downloading files required!
